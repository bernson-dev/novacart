# NovaCart

**NovaCart** — доработанная платформа для создания и управления интернет-магазинами на базе **OpenCart 3.0.3.9**.

Проект сохраняет привычную архитектуру OpenCart 3.x, но развивает её в сторону более удобной административной панели, улучшенной производительности, расширенных инструментов управления каталогом и дополнительных встроенных возможностей.

## Основные особенности

* База — **OpenCart 3.0.3.9**.
* Мультиязычность **RU / UK / EN**.
* Обновлённая и доработанная административная панель.
* Улучшенные инструменты управления каталогом.
* Массовое добавление атрибутов на нескольких языках.
* Встроенная система блога.
* Управление режимом обслуживания непосредственно из панели администратора.
* Оптимизированная файловая система кеширования.
* Расширенные инструменты разработчика и обслуживания магазина.
* Улучшенный установщик с дополнительными параметрами установки.
* Аварийная очистка кеша модификаторов с защищённым одноразовым токеном.
* Поддержка стандартной системы модификаций OpenCart / OCMOD.
* Сохранена совместимость с архитектурой расширений OpenCart 3.x там, где изменения NovaCart её не затрагивают.

## Структура проекта

Основные файлы устанавливаемой системы находятся в каталоге:

```text
upload/
```

Основные компоненты:

```text
upload/
├── admin/      # административная панель
├── catalog/    # витрина магазина
├── image/      # изображения и ресурсы
├── install/    # установщик
├── system/     # ядро, библиотеки, кеш и системные компоненты
└── index.php   # точка входа витрины
```

## Административная панель

В NovaCart административная часть OpenCart существенно дорабатывается.

В частности, проект содержит дополнительные инструменты для:

* управления каталогом;
* работы с категориями;
* массового создания атрибутов;
* управления режимом обслуживания;
* работы с кешем и модификациями;
* диагностики и обслуживания магазина.

## Массовое добавление атрибутов

В административной панели реализован отдельный инструмент массового добавления атрибутов.

Поддерживаются:

* создание нескольких атрибутов за одну операцию;
* несколько языков;
* определение основного языка;
* автоматическое заполнение отсутствующих переводов;
* проверка существующих атрибутов;
* пропуск дубликатов;
* отчёт о добавленных и пропущенных значениях.

## Блог

NovaCart содержит встроенную систему блога с административным управлением:

* статьями;
* категориями;
* отзывами;
* настройками блога.

Блог является частью самой системы и не требует установки отдельного расширения.

## Кеширование

В проекте присутствует собственный файловый кеш `FastFile`.

Он использует:

* распределение файлов кеша по каталогам;
* JSON для массивов;
* текстовый формат для остальных данных;
* TTL через время модификации файла;
* атомарную запись через временный файл и `rename()`;
* автоматическое удаление повреждённых или просроченных записей.

Такой подход уменьшает количество лишних файловых операций и позволяет избежать хранения большого количества файлов в одном каталоге.

## Установка

Скопируйте содержимое каталога:

```text
upload/
```

в корневой каталог сайта и откройте сайт в браузере.

Если `config.php` ещё не создан, NovaCart автоматически перенаправит в установщик.

Установщик создаёт конфигурацию магазина и административной панели и позволяет настроить подключение к базе данных.

## Требования

Точные системные требования будут уточняться по мере стабилизации проекта.

Для разработки рекомендуется использовать современную конфигурацию PHP и MySQL/MariaDB, совместимую с OpenCart 3.x.

## Статус проекта

NovaCart находится в активной разработке.

Проект постепенно получает:

* улучшения интерфейса;
* оптимизации производительности;
* исправления архитектуры OpenCart 3.x;
* новые административные инструменты;
* улучшения безопасности;
* современные механизмы работы с кешем и данными.
